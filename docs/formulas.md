# Формулы и единицы

Инженерные `issues` сохраняются для анализа после полёта и не являются условиями допуска. Launch допускается при оплаченном носителе, непустой сборке и стоимости ≤ 110 M$.

Для перелёта `P_hotel = P_bus + P_heater`, `E_end = clamp(E_start + (P_solar − P_hotel)×72h, 0, E_usable)`. При дефиците время обесточивания = `E_start/(P_hotel−P_solar)`. Для торможения оценивается фактический Δv по текущему топливу, а не номинальный резерв; топливо расходуется в конце этапа торможения. На витке отключённые приборы исключаются из нагрузки; обесточивание срабатывает при фактическом исчерпании заряда, с пропорционально сохранённой частью измерений. Положительный запас энергии может пережить несколько витков с отрицательным балансом.

Исходный код: src/engine/calculations.ts и src/engine/simulation.ts; константы: src/data/missionConfig.ts.

| Величина         | Формула                                                      | Единица         |
| ---------------- | ------------------------------------------------------------ | --------------- |
| dryMass          | Σ masses компонентов                                         | kg              |
| wetMass          | dryMass + propellant                                         | kg              |
| payload          | launcher.payload × orbit.payloadFactor                       | kg              |
| Δv               | Isp × 9.80665 × ln(wetMass/dryMass)                          | m/s             |
| Δv margin        | available − profile.required − 150                           | m/s             |
| burn mass        | wetMass × (1 − exp(−profile.required/(Isp×g0)))              | kg              |
| sunPower         | panelRated × 0.9 × 0.95                                      | W               |
| peakLoad         | bus + instruments + transmitter + heater                     | W               |
| shadowLoad       | bus + 0.4 × instruments + heater                             | W               |
| shadowNeed       | shadowLoad × shadowHours                                     | Wh              |
| usableBattery    | nominalWh × 0.8 × 0.9                                        | Wh              |
| cycleMargin      | (sunPower − peakLoad) × sunHours × 0.9 − shadowNeed          | Wh              |
| generated        | Σ instrumentMbps × operatingHours × 3600/1000                | Gbit/виток      |
| downlinkCapacity | antennaMbps × contactHours × 3600/1000                       | Gbit/виток      |
| deliveryRatio    | min(1, capacity/generated); при generated=0 → 1              | доля            |
| memoryRatio      | min(1, memory/(generated×4)); при generated=0 → 1            | доля            |
| potentialScience | Σ weights × orbitFactor × 4 × min(deliveryRatio,memoryRatio) | игровые единицы |
| cost             | launcher + Σ installed parts + current test credit + fuel×0.012 + overhead | M$ |
| actual science   | полученная наука × сохранённая доля × переданная доля        | игровые единицы |

За виток заряд сначала пополняется до полезной ёмкости от солнечного избытка с учётом КПД, затем расходуется в тени. Выключенный радар уменьшает нагрузку и перестаёт генерировать данные/науку. Никакое значение W не сравнивается с Wh.

При нулевом потоке deliveryRatio равен 1 для корректной арифметики; science остаётся 0, контракт не выполняется. Отрицательные/нечисловые вводы отвергаются. Потери данных и оставшаяся в памяти наука не начисляются как доставленные.

Научная оценка = clamp(delivered/120, 0, 1) ×100. Итоговая оценка ограничена [0,100]. Отдельный success требует delivered ≥120, health>0, time≤168 h.

В v2 бюджет расходуется при покупке. `spending = Σ ownedParts + reservedLauncher + purchasedFuel×0.012 + Σ allPaidTests`; `cash = 110 − spending`. Overhead равен стоимости склада и испытаний, не вошедших в текущий кредит. Поэтому `calculate(build).costMUsd = spending(economy)` без двойного счёта. Снятие с аппарата не возвращает деньги; продажа неустановленного оборудования возвращает номинал. Испытания не возвращаются.

Кредит надёжности = сумма стоимости только пройденных испытаний с совпадающим fingerprint (сортированные ID модулей, орбита, носитель, количество топлива). Покупка запасной детали не меняет fingerprint. Изменение конструкции, топлива, орбиты или носителя делает допуск неактуальным. Возврат к точно испытанному проекту восстанавливает допуск без повторной оплаты.

SetOperations влияет на следующий расчётный виток/сеанс. Отключённые приборы исключаются из данных, науки и нагрузки; уже сохранённые измерения остаются. Для экваториальной области научный коэффициент 0.65, для полюса 1. Доступная передача = штатная ёмкость окон × выбранная доля (0.25/0.5/1) × ориентация антенны (Земля=1, сложена=0). Визуальная интерполяция использует тот же результат перехода. Команды разрешены на паузе, но заблокированы при кризисе и после результата.
