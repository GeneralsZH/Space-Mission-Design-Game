## Обновление: интерактивная 3D-модель

Добавлены SpacecraftView (переключатель/доступность/fallback) и лениво загружаемый SpacecraftScene (React Three Fiber/Three.js). Браузерный скриншот: [3D-модель](screenshots/spacecraft-3d.png).

После обновления прошли **39 unit/integration**, **8 прежних сценариев миссии** и **3 новых сценария WebGL**. TypeScript, ESLint и production build успешны, npm audit — 0 уязвимостей. Vite сообщает ожидаемое предупреждение о размере отдельного 3D-чанка (~948 KB / 249 KB gzip); он загружается динамически, без внешних моделей и текстур.

Новые сценарии: настоящий WebGL-рендер в Chromium/SwiftShader; поворот, масштаб и клавиатура; разнесённая сборка; визуальное изменение при установке радара; переключение 2D/3D; отказ создания контекста; потеря контекста; Reduce Motion и сохранение выбора. Изменения проверяются по изображению canvas, а не наличию пустого элемента. Дополнительно unit-тесты проверяют перенос старой графической настройки без изменения проекта, seed и команд полёта.

Сцена проверена с программным WebGL. Для этого только 3D-файл тестов использует SwiftShader; регрессионный сценарий использует SVG и обычный браузерный renderer. GPU-сценарии выполняются последовательно, чтобы Windows не создавал одновременно несколько программных контекстов. Ранний лишний GPU-probe убран; в SVG-режиме WebGL-контексты не создаются.
