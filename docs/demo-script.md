# 30-second demonstration

Use English, a prepared purchased/assembled modern-model spacecraft, live playback at 8x, and an already completed second design in history. Preparation is outside the 30 seconds; do not imply that engineering design takes seconds.

| Time    | Screen / action                                                                                    | Narration                                                                                                                    |
| ------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 0-6 s   | Orbit screen; select low then high polar.                                                          | "Design a lunar orbiter. Your hardware and orbit determine mass, fuel, eclipse demand and data return."                      |
| 6-14 s  | Launch; briefly show liftoff, safe-mode decision, orbit. Use a prepared recording if timings vary. | "Fly the design in 3D. Engineering choices drive the outcome, including power loss and missed science."                      |
| 14-23 s | NASA science; select a sample, point to comparison table.                                          | "Compare simulated access with real NASA LROC illumination. These are archived observations, not invented ice measurements." |
| 23-30 s | Prepared completed debrief; compare previous attempt, download HTML report.                        | "Revise, compare results, and export the assumptions, evidence and engineering lessons."                                     |

Narration: 67 words, approximately 30 seconds. Use an honestly labeled recording when cutting between pre-completed runs. Sources and limitations remain visible in the app and report.

## Reliable full demonstration (untimed)

Begin from a new project; purchase and install a bus, camera, composition spectrometer, antenna, solar array, battery, engine and protection. Buy propellant and launch service, review engineering constraints, and run the complete mission in Step mode. Explain each crisis, inspect data return, revise the orbit and repeat. Use the new-model journey test and the original student purchase/assembly browser test as reproducible examples. Never claim that a preloaded fixture is a student's independent design.
