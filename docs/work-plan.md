# План реализации

Исправление повтора после reload: видимый сохранённый полёт на главной; атомарный повтор с той же сборкой из центра управления и отчёта; новое состояние часов/Canvas при повторе той же фазы; сохранение ручного выбора движения на Windows; network-first HTML и корректный fallback старых JS-ресурсов без удаления LocalStorage.

Дополнение по запросу пользователя: разрешён технически неудачный запуск; предварительные инженерные статусы заменены сырыми измерениями. Добавлены причинные отказы на отдельных этапах, отдельная фаза записи происшествия, 3D-разрушение и баллистические обломки, непрерывный уход аппарата с курса и отложенный разбор причин. Сценарные пороги и пределы реализма описаны в assumptions.md.

Обновление v2: самостоятельные закупки, склад, пустой проект, 3D-мастерская с узлами и drag-and-drop, оплаченная заправка/носитель, платные протоколы испытаний с актуальностью, фактические ограничения без рецептов, бортовые команды и разбор расходов/решений. Новая версия сохранений совместима с v1; тесты сценария студента добавлены.

Источник требований: Space_Mission_Architect_TZ_Codex.docx v1.0 и сопровождающий txt. Пользователь поручил выполнить весь проект. React-приложение находится в mission-architect; неиспользуемый Flutter starter и временные результаты сборки/проверок удалены при последующей очистке по поручению пользователя.

1. Каркас Vite, strict TypeScript, Tailwind, ESLint, Vitest, Playwright.
2. Типизированный каталог, контракт, чистые формулы и приёмочные тесты.
3. Конструктор, SVG аппарата, четыре баланса, отмена, орбиты и носители.
4. Детерминированный автомат, четыре витка, аварии и решения.
5. Отчёт, replay, сохранение, проверяемый JSON, RU/EN.
6. Адаптивность, доступность, браузерные проверки, README и допущения.

Все шесть этапов выполнены. Проверки этапов зафиксированы в docs/verification.md: 37 unit/integration, 8 Playwright, strict TypeScript, lint и build. Коммиты выполнены внутри отдельного репозитория веб-приложения.
